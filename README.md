# DrillOps Releases

Публичный канал поставки **DrillOps Desktop** — установщики Windows, каталог версий для автообновления клиентов и материалы релизов.

> Исходный код DrillOps находится в **приватном** репозитории и сюда не публикуется.  
> Этот репозиторий содержит только дистрибутивы, метаданные и документацию для пользователей.

---

## Скачать DrillOps Desktop

Актуальный установщик — в разделе **[Releases](https://github.com/Vanilla76e2/DrillOps.Releases/releases)**.

1. Откройте [последний релиз](https://github.com/Vanilla76e2/DrillOps.Releases/releases/latest).
2. В блоке **Assets** скачайте `DrillOps.Desktop-Setup-<версия>.exe`.
3. Запустите установщик на рабочей станции Windows (x64).

Для работы Desktop нужен доступ к серверу **DrillOps API** вашей организации (URL и учётная запись выдаёт администратор).

---

## Автообновление

Клиент DrillOps Desktop при входе на сервер проверяет совместимость и наличие новой версии.

Каталог версий для серверов DrillOps — файл **[index.json](./index.json)** в корне репозитория:

```
https://raw.githubusercontent.com/Vanilla76e2/DrillOps.Releases/main/index.json
```

В каталоге указывается **только последняя** рекомендуемая версия Desktop (версия, contract, ссылка на setup, SHA-256).  
Исторические сборки остаются в [Releases](https://github.com/Vanilla76e2/DrillOps.Releases/releases) для ручной загрузки.

Сервер API (Docker) обновляется отдельно администратором инфраструктуры — не через этот каталог.

## Версионирование

Версии имеют вид `0.1.1-alpha`, `0.2.0` и т.д.  
Совместимость Desktop с сервером определяется **contract version** (целое число в `index.json`), а не только номером релиза.

Если после обновления Desktop не подключается к серверу — обратитесь к администратору: возможно, сначала требуется обновить API.
